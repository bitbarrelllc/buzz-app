# Diff viewer

Shows code changes posted in a conversation as a diff card, so you can read what changed instead of raw patch text.

## Where you'll find it

- In conversations, when an agent or another app posts a code change. The card shows the file name, any description, and a link to the commit or repository when one is included.
- **Expand diff** opens the full change, where you can switch between **Unified** and **Split** layouts.

## If you turn it off

- Code changes show as plain patch text under the file name and description. Nothing is lost.

## Good to know

- Buzz doesn't create these messages itself. They come from agents and other apps.
- A large change may arrive shortened. The card then says **Diff truncated.** and links to the full change at the source repository when it can.
