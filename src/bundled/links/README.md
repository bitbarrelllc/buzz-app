# Links

Makes links in messages easier to scan by adding an icon for the service or Buzz destination, and by shortening long web addresses.

## Where you'll find it

- In messages. Links to GitHub, Google Drive, Docs, Sheets and Slides, Figma, Notion, Slack, Dropbox, OneDrive, GitLab, YouTube, Loom, Zoom and Microsoft Teams get that service's icon. Other web links get a globe.
- Buzz links to a channel, message or thread get a matching icon, with a lock for private channels.
- Long web addresses are shortened in the message. The full address is still what opens.

## If you turn it off

- Links still work and open the same way. Previews and the **Open in browser** and **Copy link** menu stay.
- Links show without icons, and long addresses show in full.

## Good to know

- Icons are chosen from the web address alone. This plugin doesn't contact the linked sites.
