# GitHub

Shows details of GitHub repositories, pull requests, issues and commits in a side panel, without leaving Buzz.

## Where you'll find it

- Click a github.com link to a repository, pull request, issue or commit in a conversation. A **GitHub** panel opens beside the conversation.
- Pull requests have **Discussion** and **Checks** tabs. Use **Open on GitHub**, or a pull request's title, to go to the full page.

## If you turn it off

- GitHub links open in your browser instead.

## Good to know

- Only public data is shown, and there's no GitHub sign-in. Private or missing items show as unavailable; open them on GitHub instead.
- Opening a panel asks GitHub for the details directly from your device. Your GitHub browser sign-in isn't sent.
- GitHub limits how often you can look things up without signing in. If you hit the limit, try again later or open the link on GitHub.
