# Channel Usage

Shows how many tokens your agents used in a channel, with an estimated cost.

## Where you'll find it

- In a channel's menu, choose **View channel usage** to open the **Usage** panel.
- Pick an agent under **Agent usage**, then a **Session**, to see input, output and cache token counts and **Estimated USD**.

## If you turn it off

- **View channel usage** and the **Usage** panel go away.
- Usage keeps being saved while **Save agent turn metrics** is on, so it's there if you turn this back on.

## Good to know

- Only in the desktop app, and only in channels you're a member of.
- It shows only usage saved on this computer while you were connected. Usage from other devices isn't included.
- Saving needs **Save agent turn metrics** in **Settings → Agents**, which is on by default. Records are encrypted and kept for 90 days.
- For a channel with a lot of saved history, it may show only part of it, and says so.
