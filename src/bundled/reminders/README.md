# Reminders

Reminders brings a message back to your attention at a time you choose.

## Where you'll find it

- **Remind me** in any message's menu. Pick a time such as **In 1 hour** or **Tomorrow at 9am**, or set your own date and time, and add an optional note.
- **Reminders** in the sidebar groups them into **Overdue**, **Today**, **Upcoming**, and **Done**. From there you can **Mark done**, **Snooze**, **Open message**, or **Cancel reminder**.
- When a reminder is due, you get a notification. You can turn these off with **Reminders** under **Settings → Notifications**.

## If you turn it off

- **Remind me**, the Reminders page, and reminder notifications go away.
- Your reminders aren't deleted. They come back if you turn it on again.

## Good to know

- Reminders work only in the desktop app.
- Each reminder, including the message preview and your note, is encrypted so only you can read it. The relay can see when it's due.
- Notifications appear only while Buzz is running. A reminder that came due while Buzz was closed notifies you the next time you open it.
