# Todos

Todos keeps a shared checklist for a channel, with a status and an optional assignee for each item.

## Where you'll find it

- The **Todos** button in a channel's header. Type in **Add a todo…** to add one, set its status to **To do**, **In progress**, or **Done**, and use **Assign to** to pick a channel member.

## If you turn it off

- The Todos button and panel go away. The list itself stays in the channel's Canvas.

## Good to know

- Todos is off by default.
- Todos are saved in the channel's Canvas under a **Todos** heading, so anyone who can see that Canvas can see them.
- Assigning a todo only adds the person's name to the list. It doesn't notify them.
- Changes save automatically. Use **Refresh** to load changes other people made.
