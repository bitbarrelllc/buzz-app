# Projects

Projects lets you browse the projects and code repositories shared in your community, and link their issues and pull requests in messages.

## Where you'll find it

- **Projects** in the sidebar lists recent projects and repositories. Open one to see its **Overview**, **Files**, **Commits**, **Pull requests**, **Issues**, **Contributors**, and linked **Channels**.
- In a channel linked to a project, the **Add issue or pull request** button in the message composer lets you search for one and insert a link.

## If you turn it off

- The Projects page and the composer button go away, and Buzz links to projects, repositories, issues, and pull requests no longer open.

## Good to know

- Files and commits come from repositories hosted by your community, not from GitHub, and you need access to the repository's linked channel to see them.
- The desktop app reads files and commits with Git on your computer, so Git must be installed. On a Mac, that means Apple's Command Line Tools.
- The list is partial: it's built from up to 100 recent announcements.
