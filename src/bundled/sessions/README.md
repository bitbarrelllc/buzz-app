# Sessions

Sessions keeps old Sessions links working by sending them to Me, where your agent chats now live.

## Where you'll find it

- It has no page of its own. Opening an old Sessions link shows **Opening Me…** and takes you to **Me**.

## If you turn it off

- Old Sessions links stop opening. Your chats aren't affected.

## Good to know

- It only redirects, so it needs Me turned on.
