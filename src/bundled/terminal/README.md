# Terminal

Opens a terminal for the current channel, running your own shell on your computer.

## Where you'll find it

- The **Toggle channel terminal** button in the channel header, or **Cmd/Ctrl+J**. You can change the shortcut in **Settings → Shortcuts**.
- **Hide terminal** keeps the shell running; **End session** stops it. Each channel has its own shell.

## If you turn it off

- The button and shortcut disappear, and every open shell ends.

## Good to know

- Available only in the Buzz desktop app on macOS and Linux.
- It's your login shell, with the same access to your files and programs as any other terminal. It isn't a sandbox.
- The shell can see the current channel, the community's address and your public key. Your private key is never passed to it.
