# Agents

Create, set up and manage your agents and teams in one place.

## Where you'll find it

- The **Agents** page, with **Your agents** and **Your teams** tabs.
- **New agent** → **Create a new agent**, **Import an agent**, or **Browse the marketplace** to copy an agent someone shared in your community.
- **More agent actions** → **Provider settings** to set up each kind of agent, such as installing or signing in to Claude or Codex.
- **More agent actions** → **Teams** to group agents under shared instructions.

## If you turn it off

- The **Agents** page goes away, so you can't create, import or browse agents.
- Agents you already have keep running and answering.
- You can still open an agent's **Settings** and **Activity** tabs from its profile.

## Good to know

- Works only in the desktop app, which keeps your agents' keys.
- To create or import an agent, turn on at least one agent type plugin, such as Claude, Codex or Builderlab.
- Hosted agents are run by their provider, whether or not this app is open.
- Importing an agent that already runs somewhere else? Stop it there first, or both will answer.
